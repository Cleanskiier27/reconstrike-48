# RECONSTRIKE 48 Rules

## Allowed
- Static and dynamic malware analysis in isolated labs
- IOC extraction, ATT&CK mapping, YARA/Sigma creation
- Building helper tooling for triage/analysis

## Prohibited
- Any activity against unauthorized or live systems
- Running samples on host OS/non-isolated network
- Sharing live malware outside approved event channels
- Plagiarism, fabricated evidence, unverifiable claims

## Safety Requirements
- VM snapshots enabled
- No host-bridge networking for malware VMs
- SHA256 logging for analyzed binaries
- Evidence chain required for each finding

## Enforcement
Judges may request replay/proof. Rule violations may result in disqualification.
